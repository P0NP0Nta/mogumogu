# もぐもぐフリック！

## StackBlitzでの起動
1. StackBlitzで「Create Project」→「Vite + React + TS」を選択
2. このZIP内のファイルで同名ファイルを置き換え（`src`フォルダも含む）
3. ターミナルで `npm install`
4. `npm run dev`（StackBlitzでは通常自動起動）

## 操作
- キーをタップ：表示された行の先頭文字
- 左右上下にフリック：各方向の文字
- 「゛」：直前の文字を濁音・半濁音に変更
- 「小」：直前の文字を小文字に変更
- 「⌫」：1文字削除
- 正解すると10点加点して次のお題へ

## カスタマイズ
`src/App.tsx` の `foods` 配列に料理名を追加・変更できます。
現在は100種類を登録しています。出題文字はひらがな表記です。
